# QOROVULBOZOR LIB V2 PRO SECURE

Kutubxona boshqaruv tizimi: kitoblar, mijozlar, berish/qaytarish, 10+ kun kechikish, savdo/POS, Click, Payme, SMS OTP, Telegram OTP/ogohlantirish, Excel, audit va Security Center.

- Domen: `qorovulbozor-lib.uz`
- PHP: 8.2+
- DB: MySQL/MariaDB
- Hosting: DirectAdmin/Apache

## Tez boshlash
1. Fayllarni `public_html` ga yuklang.
2. MySQL baza yarating.
3. `/install/` ni oching.
4. `config/config.php` ni yarating/sozlang.
5. Cron va API kalitlarini sozlang.
